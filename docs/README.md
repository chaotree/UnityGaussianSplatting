## 🔧 技术特性

### 核心功能

- **实时渲染**: 支持数百万个 splat 的实时渲染
- **高质量**: 基于物理的光照模型和抗锯齿
- **多格式支持**: 支持 PLY、SPZ 等多种数据格式
- **数据压缩**: 多种压缩格式平衡质量和性能
- **编辑功能**: 完整的交互式编辑工具

### 渲染管线支持

- **Built-in Render Pipeline**: 原生支持
- **Universal Render Pipeline (URP)**: 完整集成
- **High Definition Render Pipeline (HDRP)**: 高级功能支持

### 性能优化

- **GPU 排序**: 使用基数排序优化渲染顺序
- **视锥体剔除**: 自动剔除不可见内容
- **分块处理**: 优化内存访问模式
- **LOD 系统**: 支持距离相关细节级别

## 📊 性能指标

### 支持规模

- **最大 splat 数量**: 860 万个（受 GPU 内存限制）
- **实时性能**: 60FPS（取决于硬件配置）
- **内存压缩**: 最高可达 20:1 的压缩比

### 数据格式

- **位置数据**: Float32/Norm16/Norm11/Norm6
- **颜色数据**: Float32x4/Float16x4/Norm8x4/BC7
- **球谐函数**: Float32/Float16/Norm11/Cluster 系列
