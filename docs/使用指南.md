## 安装和设置

### 系统要求

- **Unity 版本**: 2022.3.7f1 或更高版本
- **渲染管线**: 支持 Built-in、URP、HDRP
- **GPU**: 支持 Compute Shader 的现代 GPU
- **内存**: 建议 8GB 以上 RAM，GPU 内存 2GB 以上

### 安装步骤

1. **通过 Package Manager 安装**

   ```
   Window → Package Manager → + → Add package from git URL
   输入: com.unity.burst
   输入: com.unity.collections
   输入: com.unity.mathematics
   ```

2. **导入 GaussianSplatting 包**

   - 下载包文件到项目的 Packages 文件夹
   - 或通过 Git 子模块添加

3. **验证安装**
   - 检查菜单栏是否有"Tools/Gaussian Splats"
   - 确认包在 Package Manager 中显示为已安装

### 项目设置

1. **渲染管线配置**

   ```csharp
   // 对于URP项目，添加渲染特性
   // 在Universal Renderer Data中添加GaussianSplatURPFeature
   ```

2. **包依赖检查**
   ```csharp
   // 确保以下包已安装
   - com.unity.burst (1.8.8+)
   - com.unity.collections (2.1.4+)
   - com.unity.mathematics (1.2.6+)
   ```

## 快速开始

### 第一步：准备数据

1. **获取 PLY 文件**

   - 使用 COLMAP、Nerfstudio 等工具生成
   - 或下载预训练的高斯点云数据

2. **文件格式要求**
   ```
   - 支持PLY格式（ASCII或二进制）
   - 支持SPZ格式（压缩格式）
   - 包含位置、旋转、缩放、颜色、球谐函数数据
   ```

### 第二步：创建资产

1. **打开资产创建器**

   ```
   Tools → Gaussian Splats → Create GaussianSplatAsset
   ```

2. **配置导入设置**

   ```
   输入文件: 选择PLY/SPZ文件
   输出文件夹: 选择保存位置
   质量设置: 选择合适的数据质量
   ```

3. **质量设置说明**
   ```
   Very High: 最高质量，文件最大
   High: 高质量，适合大多数用途
   Medium: 平衡质量和大小
   Low: 较小文件，质量适中
   Very Low: 最小文件，基础质量
   Custom: 自定义格式设置
   ```

### 第三步：设置渲染器

1. **创建 GameObject**

   ```csharp
   // 在场景中创建空GameObject
   GameObject splatObject = new GameObject("GaussianSplat");
   ```

2. **添加渲染器组件**

   ```csharp
   // 添加GaussianSplatRenderer组件
   GaussianSplatRenderer renderer = splatObject.AddComponent<GaussianSplatRenderer>();
   ```

3. **配置渲染器**

   ```csharp
   // 设置资产
   renderer.asset = gaussianSplatAsset;

   // 设置渲染参数
   renderer.m_SplatScale = 1.0f;
   renderer.m_MaxDistance = 1000.0f;
   renderer.m_OpacityScale = 1.0f;
   renderer.m_SHOrder = 3;
   ```

## 数据导入

### 支持的格式

#### PLY 格式

```
element vertex 1000000
property float x
property float y
property float z
property float nx
property float ny
property float nz
property float scale_0
property float scale_1
property float scale_2
property float rot_0
property float rot_1
property float rot_2
property float rot_3
property float f_dc_0
property float f_dc_1
property float f_dc_2
property float f_rest_0
...
```

#### SPZ 格式

- 压缩的 PLY 格式
- 更小的文件大小
- 更快的加载速度

### 导入选项

#### 数据压缩格式

**位置数据格式**

```csharp
Float32: 完整精度，12字节/点
Norm16: 16位归一化，6字节/点
Norm11: 11位归一化，4字节/点
Norm6: 6位归一化，2字节/点
```

**颜色数据格式**

```csharp
Float32x4: 完整精度，16字节/点
Float16x4: 半精度，8字节/点
Norm8x4: 8位归一化，4字节/点
BC7: 压缩纹理，1字节/点
```

**球谐函数格式**

```csharp
Float32: 完整精度
Float16: 半精度
Norm11: 11位归一化
Cluster64k: 64K聚类（共享系数）
```

#### 质量预设

```csharp
// 高质量设置
Position: Norm11 (4字节)
Scale: Norm11 (4字节)
Color: Float16x4 (8字节)
SH: Norm11 (4字节)
总大小: ~20字节/点

// 低质量设置
Position: Norm6 (2字节)
Scale: Norm6 (2字节)
Color: BC7 (1字节)
SH: Cluster4k (共享)
总大小: ~5字节/点
```

## 故障排除

### 常见问题

#### 1. 内存不足

```
错误: GPU缓冲区分配失败
解决:
- 减少splat数量（最大8.6M）
- 使用更激进的压缩格式
- 检查GPU内存是否足够
```

#### 2. 渲染错误

```
错误: 资产格式不兼容
解决:
- 检查资产版本号
- 重新导入资产
- 验证数据完整性
```

#### 3. 性能问题

```
问题: 帧率过低
解决:
- 减少splat数量
- 使用更激进的压缩
- 增加排序间隔
- 检查GPU性能
```

#### 4. 兼容性问题

```
问题: 在某些设备上不工作
解决:
- 检查Unity版本（需要2022.3.7f1+）
- 确认GPU支持Compute Shader
- 验证渲染管线设置
```

// 创建基础渲染器
public class BasicGaussianSplatExample : MonoBehaviour
{
    public GaussianSplatAsset asset;
    private GaussianSplatRenderer renderer;

    void Start()
    {
        // 创建渲染器

        renderer.asset = asset;

        renderer.m_MaxDistance = 1000.0f;
        renderer.m_OpacityScale = 1.0f;
        renderer.m_SHOrder = 3;
    }

### 交互式示例

```csharp
// 交互式编辑示例
public class InteractiveGaussianSplatExample : MonoBehaviour
{
    public GaussianSplatRenderer renderer;
    public Camera editorCamera;

    void Update()
    {
        // 鼠标选择
        if (Input.GetMouseButtonDown(0))
        {
            Vector2 mousePos = Input.mousePosition;
            Vector2 rectSize = new Vector2(10, 10);
            Vector2 rectMin = mousePos - rectSize * 0.5f;
            Vector2 rectMax = mousePos + rectSize * 0.5f;

            renderer.EditUpdateSelection(rectMin, rectMax, editorCamera, false);
        }

        // 键盘操作
        if (Input.GetKey(KeyCode.Delete))
        {
            renderer.EditDeleteSelected();
        }
    }
}
```
