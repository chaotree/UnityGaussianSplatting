# Unity GaussianSplatting 渲染流程文档

## 概述

Unity GaussianSplatting Package 是一个基于 3D 高斯点云的高质量实时渲染系统。它实现了论文《3D Gaussian Splatting for Real-Time Radiance Field Rendering》中提出的技术，能够在 Unity 中实时渲染大规模的点云数据。

## 核心架构

### 1. 主要组件

#### 1.1 GaussianSplatAsset

- **作用**: 存储高斯点云数据的 ScriptableObject 资源
- **数据格式**: 支持多种压缩格式的位置、缩放、颜色和球谐函数数据
- **最大支持**: 860 万个 splat 点（受 GPU 缓冲区 2GB 限制）

#### 1.2 GaussianSplatRenderer

- **作用**: 主要的渲染组件，负责 GPU 资源管理和渲染调度
- **功能**:
  - 数据上传到 GPU
  - 视锥体剔除和排序
  - 渲染状态管理
  - 编辑功能支持

#### 1.3 GaussianSplatRenderSystem

- **作用**: 全局渲染系统，管理所有活跃的 GaussianSplatRenderer
- **功能**:
  - 注册/注销渲染器
  - 相机预剔除
  - 渲染顺序管理

## 渲染管线

### 1. 数据预处理阶段

#### 1.1 资产创建流程

```
PLY/SPZ文件 → GaussianSplatAssetCreator → GaussianSplatAsset
```

**关键步骤**:

1. **文件解析**: 读取 PLY 或 SPZ 格式的原始数据
2. **数据压缩**: 根据质量设置选择压缩格式
3. **Morton 排序**: 使用 Z-order 曲线优化内存访问
4. **分块处理**: 将数据分割为 256 个 splat 的块
5. **纹理生成**: 将颜色数据打包为 2D 纹理

#### 1.2 数据布局

- **位置数据**: 存储在 GraphicsBuffer 中
- **其他数据**: 旋转、缩放存储在 GraphicsBuffer 中
- **颜色数据**: 存储在 2D 纹理中（支持 BC7 压缩）
- **SH 数据**: 存储在 GraphicsBuffer 或纹理中
- **分块数据**: 存储在 GraphicsBuffer 中

### 2. 运行时渲染阶段

#### 2.1 初始化阶段

```csharp
// 1. 注册渲染器到全局系统
GaussianSplatRenderSystem.instance.RegisterSplat(renderer);

// 2. 创建GPU资源
CreateResourcesForAsset();
- 分配GraphicsBuffer用于位置、旋转、缩放数据
- 创建颜色纹理
- 初始化排序缓冲区
- 设置计算着色器

// 3. 上传数据到GPU
SetAssetDataOnMaterial(materialPropertyBlock);
```

#### 2.2 每帧渲染流程

**步骤 1: 相机预剔除**

```csharp
OnPreCullCamera(camera)
├── GatherSplatsForCamera() // 收集可见的splat对象
├── 按渲染顺序和距离排序
└── 设置渲染目标
```

**步骤 2: 视锥体剔除和排序**

```csharp
SortPoints(commandBuffer, camera, matrix)
├── 计算每个splat到相机的距离
├── GPU基数排序 (DeviceRadixSort)
└── 生成排序后的索引缓冲区
```

**步骤 3: 视图数据计算**

```csharp
CalcViewData(commandBuffer, camera)
├── 计算3D协方差矩阵
├── 投影到2D屏幕空间
├── 计算椭圆的轴和缩放
└── 应用球谐函数光照
```

**步骤 4: 渲染绘制**

```csharp
DrawProcedural()
├── 使用排序后的索引
├── 每个splat绘制一个四边形
├── 在片段着色器中计算高斯权重
└── 累积到渲染目标
```

**步骤 5: 合成阶段**

```csharp
Composite()
├── 将高斯splat结果与场景合成
├── 应用伽马校正
└── 输出最终颜色
```

### 3. 着色器管线

#### 3.1 顶点着色器 (RenderGaussianSplats.shader)


**关键计算**:

- 从`_SplatViewData`获取预计算的视图数据
- 生成 2x2 的四边形覆盖 splat 区域
- 应用椭圆的轴向量进行变形

#### 3.2 片段着色器

```hlsl
// 主要功能:
// 1. 计算高斯权重
// 2. 应用透明度
// 3. 处理选择状态
// 4. 输出累积颜色
```

**高斯权重计算**:

```hlsl
float power = -dot(i.pos, i.pos);
half alpha = exp(power);
```

#### 3.3 计算着色器 (SplatUtilities.compute)

**核心内核**:

- `CSSetIndices`: 初始化索引
- `CSCalcDistances`: 计算到相机的距离
- `CSCalcViewData`: 计算视图相关数据
- `CSSelectionUpdate`: 更新选择状态

**视图数据计算**:

```hlsl
// 1. 加载splat数据
SplatData splat = LoadSplatData(idx);

// 2. 计算3D协方差
float3x3 rotMat = CalcMatrixFromRotationScale(splat.rot, splat.scale);
CalcCovariance3D(rotMat, sigma0, sigma1);

// 3. 投影到2D
float3 cov2d = CalcCovariance2D(worldPos, sigma0, sigma1, matrixV, matrixP, screenParams);

// 4. 计算椭圆轴
DecomposeCovariance(cov2d, v1, v2);
```

### 4. 渲染管线集成

- 支持体积渲染集成

## 性能优化

### 1. 内存优化

- **数据压缩**: 支持多种压缩格式减少内存占用
- **分块处理**: 256 个 splat 的块优化缓存访问
- **Morton 排序**: Z-order 曲线优化内存局部性

### 2. GPU 优化

- **GPU 排序**: 使用基数排序在 GPU 上排序
- **批量渲染**: 使用`DrawProcedural`批量绘制
- **计算着色器**: 并行计算视图数据

### 3. 渲染优化

- **视锥体剔除**: 只渲染可见的 splat
- **LOD 系统**: 支持距离相关的细节级别
- **透明度排序**: 从后到前排序确保正确混合

## 总结

Unity GaussianSplatting Package 提供了一个完整的 3D 高斯点云渲染解决方案，具有以下特点：

1. **高性能**: 支持数百万个 splat 的实时渲染
2. **高质量**: 基于物理的光照模型和抗锯齿
3. **易用性**: 简单的 API 和编辑器工具
4. **可扩展**: 支持自定义着色器和渲染管线
5. **跨平台**: 支持 PC、移动和 VR 平台

该系统的核心优势在于将复杂的 3D 高斯渲染技术封装为易于使用的 Unity 组件，同时保持了高性能和高质量的输出。
